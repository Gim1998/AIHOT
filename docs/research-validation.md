# 需求研究功能验证

实现前列出的失败边界（通过真实数据库、HTTP 接口与本地模拟上游验证）：

- 把模型编造的付款金额、错误出处、未采集评论当证据；无材料仍生成购买理由。
- 把其他人的回复误认成原帖作者，把评论样本当完整讨论；删除内容仍进入下一次评估。
- 评论刷新失败清空有效缓存、不断重试耗尽额度、关闭采集时仍访问上游。
- 正文或评论更新后，旧评估仍显示；重复处理对同一材料重复支付。
- 相似关键词误称已验证需求；同一作者、重复正文、隔离或撤回帖子增加独立案例数。
- 私人笔记、付款记录、手动材料进入公共详情、RSS、搜索或匿名接口。
- 未登录/缺少 CSRF 可以编辑；两个窗口相互覆盖；重复保存创建多份记录。
- 手动输入危险 URL、超长材料或无效状态；保存笔记隐式触发模型或发布。
- 首页恢复分类/精选、隐藏低分，或改变既有排序。

可重复检查：项目完整数据库测试中的 `tests/research.test.ts`，以及 `scripts/check-research-site.ts <base>`。外部服务只在独立的线上读取核验中使用；自动化测试不访问外网。
