# 新手机会首页

参考 [IdeaBrowser 的数据库页](https://www.ideabrowser.com/database) 的“产品点子在前、用户问题在后、明确行动入口”信息顺序，使用本站原有品牌、配色及实际数据，没有复制其文案、图片或收入预测。

首页与 `/all` 共用页面：入门指引、搜索、机会卡片、数字分页。桌面两列、窄屏一列。导航改为“发现机会”，收藏仍复用原有浏览器存储；私人验证入口要求管理员登录。

每条已整理的机会卡片展示模型提出的最小交付（明确标为待验证）、有依据的用户与障碍、费用证据、最小验证动作及研究参考分。点开进入原有详情的研究区域。低分和未评分内容仍保留；没有分类、精选或额外收入评分。

如果内容未整理、提示词版本过期、正文或评论发生变化，首页显示原始线索，不能从来源名称或帖子标题编造产品机会。被判为推广、已解决或无关的材料不展示模型提议的产品切口。页面统计的“机会草稿”是当前页数量，不是全站已验证市场数量。

后端通过公开读取层按页批量读取研究摘要，不对每张卡片调用详情接口或模型。搜索索引包含有依据的研究字段和可展示的工具切口，不包含私人笔记。已有内容会按原定任务逐步整理；本次没有改变模型提示词、评分权重、采集频率或套餐。

验证边界：不泄漏私人笔记与原文全文；不展示旧修订/旧评论的机会判断；原始资料不伪装成机会；零分、未评分和排序不受影响；卡片显示的工具标题能搜索。集成用例为 `tests/opportunity-home.test.ts`，可重复 HTTP 验收为 `node scripts/check-opportunity-home.ts <base>`；浏览器用 ChatGPT 内置浏览器核对桌面/手机与收藏、搜索、详情入口。
